全新界面设计：鼠尾草绿配色、留白式排版与更清晰的操作动线。

- 全新配色与字体：浅色米灰底、深色橄榄底两套主题，主色改为鼠尾草绿；品牌标识换为字母 B 新标志。
- 顶栏改为 64px 高（浮窗 55px），画布标签改为 pill 样式，保存状态改为绿点指示；撤销/重做与「新建提示词」从顶栏移出。
- 新增左侧工具栏：选择 (V)、平移 (H)、新建提示词 (N)、导入图片；平移模式下拖动任意位置即可移动画布。
- 撤销/重做改为画布右上角悬浮按钮；缩放控件移到右下角（缩小/百分比/放大/查看全部）；左下角新增操作提示文案。
- 提示词节点重设计：260px 窄卡、「提示词」标签栏、14px 大字号正文、生成主按钮（深色底、悬停变绿）；更多操作收进 ⋯ 菜单。
- 图片节点重设计：白边圆角卡片、半透明毛玻璃 ⋯ 按钮、底部图片名与尺寸标签；选中后下方浮出「继续修改 / 预览 / 下载」工具条。
- 连线统一灰调：生成实线、参考虚线 (5 5)、分支点线 (2 5)，选中关联时高亮为绿色。
- 菜单、对话框、预览与标注界面统一圆角与毛玻璃背景；轻提示改为顶部居中深色胶囊。
- 空状态改为大加号按钮 +「双击画布，写下一个想法」。
