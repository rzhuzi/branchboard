# Branchboard

Branchboard 是一个本地优先的 Chrome 生图画布。它不调用或反代 OpenAI
API，而是在用户已经登录的 ChatGPT 页面上提供浮动画布。

## 当前能力

- 无限缩放和拖拽画布
- 多画布标签页和一键新建画布
- 提示词节点与图片节点
- 标注模式：复制提示词后由用户粘贴和发送，生成图可直接标注
- 自动模式：从节点自动填入并发送，生成完成后自动把图片带回画布
- 自动节点可以携带上游图片作为参考图
- ChatGPT 同一生成图即使使用不同临时 URL，也只会按内容回收一次
- 删除正在运行的节点会同时停止 ChatGPT 生成并立即释放任务
- ChatGPT 只返回文字时会明确结束任务，不会一直占用运行状态
- 生成结果、参考图和提示词分支使用系统管理的关系线
- 选择或运行提示词后导入图片，自动建立生成结果关系
- ChatGPT 页面内可收起、展开、拖动和调整尺寸的完整浮动画布
- 浮动画布会记住上次的位置和尺寸
- 最小化后的画布图标可自由拖动并记住位置
- 浮动画布展开后会自动重新定位画布内容
- 图片节点内置画笔、矩形、箭头、颜色、粗细、撤销和保存标注
- 一键把画布图片复制回剪贴板
- 剪贴板写入由扩展隐藏页面完成，不受 ChatGPT 内嵌页面策略限制
- 文字复制在 Clipboard API 被策略限制时会自动切换兼容通道
- IndexedDB 本地自动保存
- 多个 ChatGPT 标签页同时编辑时进行版本检测和字段级合并
- 保存失败、存储空间不足和结果路由失败都有可见提示及重试入口
- 不读取 ChatGPT Cookie，不需要 API Key

## 安装发布包

1. 解压 `branchboard-v1.0.0.zip`。
2. 打开 `chrome://extensions`。
3. 开启右上角“开发者模式”。
4. 点击“加载已解压的扩展程序”，选择刚解压的目录。
5. 打开或刷新 ChatGPT 页面，右下角会出现橙色 Branchboard 图标。

ZIP 内的根目录直接包含 `manifest.json`，不需要再次进入子目录。

## 从源码构建

```powershell
npm install
npm run icons
npm test
npm run build
npm run release:check
```

然后：

1. 打开 `chrome://extensions`。
2. 开启右上角“开发者模式”。
3. 点击“加载已解压的扩展程序”。
4. 选择本项目的 `dist` 文件夹。
5. 打开或刷新 ChatGPT 页面，右下角会出现橙色画布图标。

## 标注模式

1. 在 ChatGPT 页面点击橙色画布图标，展开浮动画布。
2. 选择顶部“标注模式”，填写提示词节点并点击“复制并收起画布”。
3. 在露出的 ChatGPT 输入框中手动粘贴并发送。
4. 图片生成后再次点击画布图标恢复画布。
5. 把生成图拖进浮动画布；若浏览器限制拖拽，可右键复制图片后在画布
   按 `Ctrl + V`。
6. 图片会自动连接到当前提示词节点。

图片进入画布后，点击图片节点下方的“标注”，可以直接绘制画笔、矩形框和
箭头。保存后标注结果会替换该节点中的图片并继续自动保存。

## 自动模式

1. 选择顶部“自动”。
2. 填写提示词后点击“发送并自动回收”。
3. 如果该节点由图片节点的“继续修改”创建，上游图片会作为参考图一并附加。
4. 浮动画布保持打开，节点依次显示填入、发送、生成、回收状态。
5. ChatGPT 生成完成后，图片自动下载到本地画布并连接到刚才运行的节点。
6. 删除正在运行的提示词节点会取消监听；如果 ChatGPT 正在生成，也会点击停止。
7. 如果 ChatGPT 已结束回复但只返回文字，扩展会在 10 秒确认期后提示没有图片并
   释放任务，可以直接运行下一个节点。

自动模式直接操作当前 ChatGPT 页面的输入框，不会把提示词或图片发送给第三方
服务。它依赖 ChatGPT 当前页面结构，如果页面更新导致控件变化，可以暂时切回
标注模式。

## 开发

```powershell
npm run dev
npm test
npm run typecheck
npm run build
npm run release:check
```

开发预览画布位于 `http://localhost:5173/canvas.html`。实际插件通过 iframe
把同一画布嵌入 ChatGPT 页面，不会再打开独立画布标签页。

项目申请 `storage`、`clipboardWrite` 和 `offscreen` 权限，并仅在
`chatgpt.com` 和 `chat.openai.com` 域名下注入浮动画布。`offscreen` 只用于
在扩展自己的隐藏文档中写入文字或图片剪贴板，不会读取剪贴板。自动模式只在用户
点击节点发送后监听本次新增的对话图片，成功回传或超时后立即停止；不会扫描历史
图片，也不会运行无人值守的批量任务。
