# Branchboard

Branchboard 是运行在 ChatGPT 网页中的本地优先无限画布扩展。它不调用或反代
OpenAI API，而是直接使用当前已登录的 ChatGPT 页面，把提示词、参考图、生成结果
和迭代分支组织在同一个浮动创作空间里。

核心流程只有一条：**创建 → 编写 → 生成 → 查看 → 修改 → 再生成。**

当前版本：**2.0.1**。默认分支为 `v2`，包含 V2 重构及生图回收、任务状态、
保存与同步修复。旧版源码保留在 `archive-main-2026-10-26` 归档标签中。

## V2 交互规则

### 画布

- 拖动空白、滚轮或中键拖动平移画布。
- `Ctrl/⌘ + 滚轮` 以光标位置为中心缩放；触控板双指缩放同样生效。
- `Shift + 拖动` 框选，`Ctrl/⌘ + 点击` 多选。
- 双击空白建立提示词并立即聚焦输入框。
- 缩放范围 10%–250%；底部提供缩放、查看全部和选中计数。
- 每个画布独立保存视角；重新打开时恢复，不会因新增图片、切换标签或生成结束
  强制重置视图。

### 提示词节点

- 正文是节点主体，没有标题栏和常驻按钮堆叠。
- 点击「生成」直接操作当前 ChatGPT 页面；点击「复制」只复制，不需要切换模式。
- 分支会复制原提示词、建立点线关系并聚焦新节点。
- 更多操作在右键菜单中；`Ctrl/⌘ + Enter` 在输入框内直接生成。
- 顶部显示「N 结果 / N 参考」，可直接定位相关节点。

### 图片节点

- 图片即节点主体，双击预览大图。
- 「⋯」始终可见，悬停或选中时显示继续修改、复制、下载、标注工具栏。
- 继续修改会新建提示词节点，建立明确的图片 → 提示词参考关系，并聚焦输入框。
- 图片标注保留原图，菜单中可恢复原图。
- 拖入、粘贴图片不再偷偷连接到最后一个提示词。只有拖到提示词节点上，才会
  作为参考图建立关系。

### 关系与生成

- 实线：生成结果；虚线：参考图；点线：提示词分支。选中连线时显示关系名称。
- 支持从图片右侧端点拖到提示词左侧端点，手动建立参考关系。
- 生成任务按顺序执行，节点内显示状态、耗时和取消入口；顶部任务中心可定位或取消。
- 生成完成不会跳转画布，只显示轻提示和「定位」操作。
- 结果按画布与提示词回收；即使浮窗最小化或切到其他画布，也不会丢失。
- 如果 ChatGPT 输入框已有草稿，扩展会停止发送，避免覆盖用户内容。
- 支持取消、超时、纯文字回复、重复结果去重和页面结构变化错误提示。
- 页面结构失效时，可复制提示词手动发送，再把图片拖回画布。

### 多画布与本地数据

- 标签页内联重命名，菜单删除（不会误触）。
- 自动保存，保存失败显示原因与重试入口。
- 多个 ChatGPT 标签页同时编辑时进行版本检测与字段级合并。
- 图片 Blob 与节点布局分开存储；编辑提示词只写入轻量文档。
- 旧版 IndexedDB 数据一次性迁移到 V2 数据库，旧库保留。

## 安装

### 发布包

1. 从 [GitHub Releases](https://github.com/rzhuzi/branchboard/releases/latest) 下载并解压 `branchboard-v2.0.1.zip`。
2. 打开 `chrome://extensions`。
3. 开启右上角「开发者模式」。
4. 点击「加载已解压的扩展程序」，选择解压后的目录。
5. 刷新 ChatGPT 页面，右下角出现 Branchboard 图标。

ZIP 根目录直接包含 `manifest.json`，无需再进入子目录。

### 从源码构建

```powershell
npm install
npm run icons
npm test
npm run build
npm run release:check
```

然后在 `chrome://extensions` 中加载 `dist` 文件夹。

## 旧版数据迁移

- V2 使用独立数据库 `branchboard-v2`，不会改写旧库 `branchboard-db`。
- 首次启动 V2 时会自动迁移旧版画布、提示词、图片、关系、收件箱图片和工作区标题。
- 迁移完成后旧库仍保留，便于回退旧版本。代价是图片会在两个数据库中各存一份。
- 确认不再需要回退后，可在扩展管理页清除旧站点数据以释放空间。
- 迁移会跳过已经存在的 V2 画布文档，重复启动不会把同一张图重复加入画布。

## 开发

```powershell
npm run dev          # 独立画布开发预览
npm run typecheck
npm test             # 纯逻辑单元测试
npm run build        # 画布 + 内容脚本 + 后台脚本
npm run release:check
```

`npm run build` 会先由 Vite 构建 `canvas.html`，再由 esbuild 将
`src/content` 和 `src/background` 分别打包为 `dist/content.js` 与
`dist/background.js`。

### 自动化测试

先构建并启动预览：

```powershell
npm run build
npm run preview -- --port 4173 --strictPort
```

另开一个终端：

```powershell
npm run test:e2e          # 浏览器交互走查
npm run test:content      # ChatGPT 新旧页面结构的图片识别与回收边界
npm run test:migration    # 旧版 IndexedDB 迁移
npm run test:performance  # 64 节点 / 16 张图片压力冒烟
npm run test:extension    # 真实扩展加载 + 后台回收 + 浮窗
```

`test:extension` 需要支持命令行加载未打包扩展的 Chromium 浏览器。本机验证使用
Microsoft Edge；Google Chrome 稳定版会忽略 `--load-extension`。手动在
`chrome://extensions` 加载扩展不受此限制。

浏览器测试使用 `puppeteer-core`，不会下载额外浏览器。

### 已验证范围

- 单元测试：浮窗尺寸、缩放锚点、滚轮平移、自动布局、结果回收、合并、图片指纹、
  旧版关系映射、剪贴板隐藏页。
- UI 自动化：双击建节点与聚焦、分支、复制、撤销/重做、画布重命名、新建/切换画布、
  深浅主题、光标锚定缩放、滚轮平移、粘贴图片、预览、继续修改、标注/恢复原图、
  删除撤销、拖动撤销、多选与框选、视角恢复、刷新恢复、双标签同步。
- 扩展自动化：真实 `chrome-extension://` 画布页加载、清单版本、剪贴板隐藏页写入、
  后台保存生成结果并回收到画布、浮窗打开/主题同步/最小化状态保持/拖动/最大化/
  还原/调整尺寸。
- 迁移自动化：旧画布、提示词、图片、关系和收件箱图片迁移成功；刷新不重复。
- 性能冒烟：48 个提示词 + 16 张 512×512 图片 + 16 条关系，本机冷加载约 0.7 秒，
  连续 30 次滚轮平移/缩放未出现 long task。

**未验证**：真实登录状态下的 ChatGPT 发送与图片捕获。该流程依赖 ChatGPT 当前
DOM 和账号会话，无法在无登录自动化环境中可靠验证。发布前应按下面的清单人工走查。

### ChatGPT 生成人工验收清单

1. 输入框为空时，点击「生成」能填入并发送。
2. 带 1–4 张参考图时，图片出现在发送内容中。
3. 生成图片能自动回到发起节点并建立实线关系。
4. 生成中点击「取消」，ChatGPT 停止且节点状态结束。
5. ChatGPT 只回复文字时，10 秒确认期后提示没有图片。
6. 输入框已有草稿时，扩展拒绝发送，不覆盖草稿。
7. 页面选择器失效时，错误信息可理解，复制提示词和手动拖图仍可用。
8. 浮窗最小化期间完成生成，重新打开后结果仍在对应画布。

## 快捷键

| 操作 | 快捷键 |
| --- | --- |
| 生成 | 提示词输入框内 `Ctrl/⌘ + Enter` |
| 撤销 / 重做 | `Ctrl/⌘ + Z` / `Shift + Ctrl/⌘ + Z` |
| 复制选中节点 | `Ctrl/⌘ + D` |
| 删除选中节点或连线 | `Delete` / `Backspace` |
| 全选节点 | `Ctrl/⌘ + A` |
| 新建提示词 | `N` 或双击空白 |
| 缩放 | `Ctrl/⌘ + +` / `Ctrl/⌘ + -` / `Ctrl/⌘ + 0` |
| 查看全部 | `Shift + 1` |

## 架构

```text
src/shared/      领域类型、IndexedDB、迁移、布局、合并、消息、剪贴板
src/canvas/      画布 UI、节点、关系边、覆盖层、编辑器状态与命令
src/content/     ChatGPT 页面浮窗、DOM 适配、发送与结果捕获
src/background/  后台存储、待回收结果、隐藏剪贴板页
public/          manifest、图标、offscreen 页面
scripts/         图标生成、扩展打包、发布校验
tests/           单元测试与 Puppeteer 浏览器走查
```

关键边界：

- 画布 UI 不直接操作 ChatGPT DOM。
- 页面自动化的选择器集中在 `src/content/dom.ts`，页面变化时影响范围可控。
- 节点操作统一走 `src/canvas/state/useEditor.ts` 的命令层，菜单、工具栏和快捷键
  不各自实现一套逻辑。
- 图片以 `assetId` 引用，不放进节点持久化数据。
- 撤销历史按画布隔离，只保存在当前会话内存中。

## 权限与隐私

扩展只申请：

- `storage`：浮窗位置、主题和本地设置；
- `clipboardWrite`：用户主动复制提示词或图片；
- `offscreen`：在扩展隐藏页完成剪贴板写入；
- `chatgpt.com` / `chat.openai.com`：显示浮动画布并执行用户主动触发的页面操作。

扩展不读取剪贴板，不读取 ChatGPT Cookie，不需要 API Key，不向开发者或第三方
发送画布数据。详见 [PRIVACY.md](PRIVACY.md)。

## 已知边界

- ChatGPT 页面 DOM 更新可能导致自动生成失败；错误会明确显示，复制和手动导入
  始终可用。
- 同一个画布 iframe 内生成任务串行排队，避免多个任务争用同一个输入框。
- 删除节点不会立即删除原始图片 Blob，便于撤销和恢复原图；清理扩展站点数据可
  彻底释放本地空间。
- 旧版数据库会保留一份迁移前数据，因此升级后本地占用会暂时增加。
- 真实 ChatGPT 生成流程仍需人工验收，自动化测试不声称覆盖该部分。
