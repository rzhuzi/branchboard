# V2 数据兼容与回退

V2 使用独立数据库 `branchboard-v2`。旧版 `branchboard-db` 在迁移后保留，便于回退。

- 首次启动自动迁移旧画布、提示词、图片和关系；重复启动不会重复导入同一份数据。
- V2 数据库版本 2 增加独立视角存储。硬编码数据库版本 1 的旧 V2 构建不能直接打开升级后的同库。
- 回退到旧版主分支只会读取旧库，不会带回升级后在 V2 中新增的内容。
- 删除画布或节点不保证立即释放图片 Blob；清理扩展本地数据会同时删除当前画布。
- 更换未打包扩展的加载目录可能改变扩展 ID，新的安装可能无法看到原安装的本地数据库。

测试范围和账号内验收步骤见 [开发与验证](DEVELOPMENT.md)，数据用途与保留方式见 [隐私说明](../PRIVACY.md)。
