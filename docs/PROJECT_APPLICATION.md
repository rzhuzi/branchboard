# Branchboard 项目申报说明

## 项目概述

Branchboard 是面向 ChatGPT 网页端生图工作流的本地优先 Chrome 扩展。它把提示词、
参考图、生成结果与图片标注组织在同一个浮动无限画布中，不需要 API Key，也不把
网页能力封装成反向代理接口。

## 要解决的问题

网页端生图通常需要在提示词、对话、下载文件和标注工具之间频繁切换。结果与提示词
容易失去对应关系，迭代过程也难以复盘。Branchboard 把工作区直接叠加在 ChatGPT
页面内，让用户保留网页端登录和交互方式，同时获得结构化的创作画布。

## 核心能力

- 多画布标签：按项目或方向拆分提示词和结果。
- 标注模式：复制提示词后手动发送，适合完全由用户确认的流程。
- 自动模式：用户点击节点后自动填入、发送并把新生成图片放回原节点。
- 图片标注：画笔、矩形、箭头、颜色、粗细、缩放、撤销和保存。
- 参考图迭代：图片可继续生成提示词节点，并作为上游参考图发送。
- 本地持久化：画布和图片保存在浏览器 IndexedDB 中。
- 并发保护：多个 ChatGPT 标签页同时修改时进行版本检测和字段级合并。

## 技术方案

项目使用 Chrome Manifest V3、React、TypeScript、React Flow、IndexedDB 和
BroadcastChannel。主要由三个深模块构成：

1. WorkspaceSession Module：统一管理画布打开、版本提交、冲突合并、多标签同步和
   本地收件箱确认。
2. ExecutionSession Module：把请求、画布和提示词节点绑定为一次执行，跨画布保留
   状态并阻止重复运行。
3. FloatingShell Module：负责 ChatGPT 页面的浮窗、拖动、缩放、最大化、最小化与
   视口边界恢复。

自动模式的网页 DOM 变化被限制在内容脚本这一处 Implementation 中，画布数据层
不依赖具体页面选择器，后续适配 ChatGPT 页面变化时影响范围更小。

## 隐私与安全

- 不调用或反代 OpenAI API，不读取 ChatGPT Cookie。
- 不收集分析数据，不向开发者服务器上传画布内容。
- 权限仅限本地存储、剪贴板写入、隐藏剪贴板页面和 ChatGPT 域名。
- 自动操作只由用户点击节点触发，不提供无人值守批量任务。
- 写入失败、存储配额不足和网页结构变化都有可见错误反馈。

完整说明见项目根目录 `PRIVACY.md`。

## 稳定性与验证

- TypeScript 全量类型检查。
- 生产构建与 Manifest V3 发布文件校验。
- 自动测试覆盖图片内容去重、剪贴板降级、浮窗边界恢复和多标签三方合并。
- 发布前在正常尺寸与小尺寸嵌入窗口中进行实际交互回归。
