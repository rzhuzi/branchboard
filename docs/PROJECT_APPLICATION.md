# Branchboard 项目申报说明

## 项目概述

Branchboard 是面向 ChatGPT 网页端生图工作流的本地优先 Chrome 扩展。它把提示词、
参考图、生成结果与图片迭代组织在同一个浮动无限画布中，不需要 API Key，也不把
网页能力封装成反向代理接口。

当前版本为 2.0.0。V2 不是旧界面的美化，而是围绕「创建 → 编写 → 生成 → 查看 →
修改 → 再生成」重新设计的产品重构。

## 要解决的问题

网页端生图通常需要在提示词、对话、生成结果、下载文件和标注工具之间频繁切换。
结果与提示词容易失去对应关系，迭代过程也难以复盘。旧版还存在模式切换、生成后
视图跳变、图片被隐式连接、按钮堆叠和撤销范围不清晰等问题。

Branchboard 把工作区直接叠加在 ChatGPT 页面内，让用户保留网页端登录和交互方式，
同时获得结构化的创作画布。

## 核心能力

- 一致的无限画布手势：平移、光标锚定缩放、框选、双击建节点。
- 按画布隔离的撤销/重做，覆盖节点创建、删除、拖动、连线和图片标注。
- 以正文为主体的提示词节点，直接提供生成、复制和分支；创建后立即聚焦。
- 图片节点支持预览、复制、下载、标注、恢复原图和继续修改。
- 生成、参考、分支三类关系用实线、虚线、点线区分，并支持手动建立参考关系。
- 生成任务串行排队，节点内联状态、耗时、取消和重试；结果自动回到发起节点。
- 生成结束只提供轻提示和定位，不强制改变画布视角。
- 多画布标签、内联重命名、自动保存、每画布独立视角和多标签字段级合并。
- 图片 Blob 与节点布局分离存储；旧版 IndexedDB 自动迁移。
- 深色/浅色主题、任务中心、快捷键帮助和紧凑工具栏。

## 交互原则

1. 用户点击什么就只执行什么，不再依赖全局模式切换。
2. 操作完成后，焦点落在用户下一步最可能需要的位置；生成则不抢焦点。
3. 未经明确指定来源的图片不自动建立关系。
4. 错误操作优先提供撤销或确认，而不是让用户迁就软件。
5. 生成过程不阻塞整个画布，也不在完成后突然跳转视图。
6. 鼠标、键盘和触控板遵循同一套画布规则。

## 技术方案

项目使用 Chrome Manifest V3、React、TypeScript、React Flow、IndexedDB、
BroadcastChannel 和 esbuild。与旧版相比，V2 的关键是边界拆分：

1. `src/canvas/state`：编辑器状态、命令层、撤销历史、自动保存、任务队列与待回收
   结果整合。节点操作只有一个实现入口。
2. `src/canvas`：画布 UI、节点、关系边、工具栏、菜单、预览和标注覆盖层。
3. `src/shared`：领域类型、IndexedDB、V1 迁移、布局算法、合并算法、消息协议和
   剪贴板。图片以资产 ID 引用，不在每次布局保存时重复序列化。
4. `src/content`：ChatGPT 页面浮窗、DOM 选择器、输入框操作、生成等待和图片捕获。
5. `src/background`：后台保存生成结果、待回收队列、隐藏剪贴板文档和动作入口。

页面 DOM 变化被限制在内容脚本内；画布数据层不依赖具体页面选择器。

## 数据与迁移

V2 使用独立的 `branchboard-v2` IndexedDB 数据库，包含文档、资产、待回收结果和
注册表四个对象仓库。旧版 `branchboard-db` 不被修改，首次启动时自动读取并迁移
画布、节点、图片、关系和收件箱图片。迁移采用确定性资产 ID，重复启动不会重复
写入同一张图片。

节点持久化数据只保存 `assetId`、位置和关系；提示词编辑只写入轻量文档。图片
Blob 单独存储，画布平移、缩放和文本修改不会重复写入图片数据。

## 隐私与安全

- 不调用或反代 OpenAI API，不需要 API Key。
- 不读取 ChatGPT Cookie。
- 只申请 `storage`、`clipboardWrite`、`offscreen` 和 ChatGPT 域名权限。
- 生成只在用户主动点击后操作当前页面，不扫描历史图片，不运行无人值守批量任务。
- 画布与图片保存在本地，不发送给开发者或第三方。

详见 [PRIVACY.md](../PRIVACY.md)。

## 验证

单元测试覆盖布局、缩放锚点、合并、迁移关系、图片指纹和剪贴板隐藏页。Puppeteer
浏览器走查覆盖画布创建、分支、撤销、框选、图片粘贴/预览/标注、视角与刷新恢复、
多标签同步。扩展测试覆盖真实扩展页加载、后台结果回收、浮窗最小化/最大化/拖动/
缩放。迁移测试覆盖旧版画布、图片、关系和收件箱。性能冒烟在 48 个提示词、16 张
512×512 图片和 16 条关系下运行平移缩放。

真实登录状态下的 ChatGPT 发送与图片捕获仍需人工验收，详见项目 README 的
「ChatGPT 生成人工验收清单」。
